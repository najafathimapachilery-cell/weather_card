# Weather Card

A simple weather card project created using HTML, CSS and JavaScript.

## Features

- Weather card design
- City name
- Temperature
- Weather condition
- Humidity
- Wind speed
- Interactive button

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Files

- `index.html` - Website structure
- `style.css` - Website design
- `script.js` - Button interaction
- `README.md` - Project information

## How It Works

The project displays weather information in a simple and clean card.

The JavaScript button provides a weather message when clicked.
